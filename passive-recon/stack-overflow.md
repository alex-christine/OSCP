# Stack Overflow

While generally thought of as a developer's resource Stack Overflow can have uses as an information gathering tool.

The site's value from an information gathering perspective is in looking at the types of questions a given user is asking or answering. If one can reasonably determine a user on Stack Overflow is also an employee of their target organization, they may be able to infer some things about the organization based on the employee's questions and answers.&#x20;
