# Site-Specific Tools

## Twitter

Tools for scraping information from Twitter.

### Twofi

Scans a user's Twitter feed and generates a personalized wordlist used for password attacks against that user.

* Twofi requires a valid Twitter API key

## LinkedIn

Tools for scraping information from LinkedIn.

### linkedin2username

a script for generating username lists based on LinkedIn data.

* Requires valid LinkedIn credentials
* Depends on a LinkedIn connection to individuals in the target organization
* The script will output usernames in several different formats.
