# Open-Source Code

If the target is a software producer it is likely that they may have some company projects available on GitHub or GitLabs. Both of these sites should be searched for projects both under an official corporate account and under a GitHub account associated with the company (e.g. an employee's corporate email).

If the projects are small the code can be examined manually..

## Examination Tools

For larger codebases, there are automated tools used to scan for useful information.

Tools such as **Gitrob** and **Gitleaks** are both used for this sort of thing.

These types of tools typically rely on regular expressions and/or entropy-based detection for finding useful information.
