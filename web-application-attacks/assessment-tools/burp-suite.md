# Burp Suite

**Burp Suite** is a GUI-based collection of tools geared towards web application security testing, arguably best-known as a powerful proxy tool. While the free Community Edition mainly contains tools used in manual testing, the commercial versions include additional features, including a formidable web application vulnerability scanner.

## Tools

Various tools exist inside the Burp Suite application that can be used for differing purposes.

### Proxy

With the proxy tool, one can intercept any request sent from the browser before it is passed on to the server. They can change almost anything about the request at this point, such as parameter names, form values, or adding new headers. This lets attackers test how an application handles unexpected arbitrary input.
