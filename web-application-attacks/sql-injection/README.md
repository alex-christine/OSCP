# SQL Injection

SQL Injection (SQLi) is a common web application vulnerability that is caused by unsanitized user input being inserted into queries and subsequently passed to a database for execution.

These types of vulnerabilities can lead to database information leakage and, depending on the environment, could lead to complete server compromise.

Most examples here are under a **PHP/MariaDB environment**.
