# DNS Enumeration

The Domain Name System (DNS)[1](https://portal.offensive-security.com/courses/pen-200/books-and-videos/modal/modules/active-information-gathering/dns-enumeration/dns-enumeration#fn1) is one of the most critical systems on the Internet and is a distributed database responsible for translating user-friendly domain names into IP addresses.

This is facilitated by a hierarchical structure that is divided into several zones, starting with the top-level root zone.
