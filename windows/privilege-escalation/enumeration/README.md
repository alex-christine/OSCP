# Enumeration

The desired information when enumerating a Windows system is not all that dissimilar from what is looked for during [Linux enumeration](../../../linux/privilege-escalation/enumeration/). Broadly there are several key pieces of information an attacker should always try to obtain:

* Username and hostname
* Group memberships of the current user
* Existing users and groups
* Operating system, version and architecture
* Network information
* Installed applications
* Running processes
