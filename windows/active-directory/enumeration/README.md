# Enumeration

The following pages will demonstrate AD enumeration, first manual then automated, against a sample `corp.com` domain. The initial steps will all be done with a low-privileged user `stephanie`. However, it is critical to remember that as the attack continues and new accounts are discovered, parts of the enumeration proceedings may need to be revisited. This persistent "rinse and repeat" process is the key to successful enumeration and works extremely well, especially in large organizations.
