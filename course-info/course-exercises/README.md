# Course Exercises

## MegaCorpone

There is a MegaCorpone.com domain that is designed to represent a fictitious company created by Offensive Security. It has a seemingly vulnerable external network presence, which is ideal to illustrate certain concepts throughout the course.

* This domain is accessible outside of the PWK VPN lab network and should only be used for passive and active information gathering during the course exercises
* It is strictly **prohibited to actively attempt to compromise** this domain

## Sandbox.local

Represents a fictitious internal company network and is used to demonstrate a full penetration test using the methodology and techniques that are covered in the course.

* Only **accessible via VPN**
