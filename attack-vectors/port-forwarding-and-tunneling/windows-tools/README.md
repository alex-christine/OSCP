# Windows Tools

All the examples in the [SSH Tunneling](../ssh-tunneling/) section were shown with Linux tools. Many corporate networks are reliant on Windows and thus it is important to understand how to utilize Windows tools for port forwarding as well as Linux ones.

The main tools on Windows are:

* `ssh.exe`
* Plink
* [Netsh](../../../windows/built-in-tools/netsh.md#port-forwarding)

`ssh.exe` and Plink will be demonstrated in the following pages and Netsh is demonstrated on the linked page.
