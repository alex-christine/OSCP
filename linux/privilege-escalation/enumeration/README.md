# Enumeration

As with many other attack techniques, escalating privileges requires attackers to collect knowledge about the target. This is accomplished by enumerating the operating system for any kind of misconfiguration or software vulnerability that can be leveraged for their purposes.

Enumeration can be done in either a manual or automated fashion. Automated is obviously faster, but sometimes manual can reveal niche vulnerabilities missed by automated tools.
