# Privilege Escalation

This section will cover the following components of privilege escalation in Linux:

* Enumerating Linux
* Exposed Confidential Information
* Insecure File Permissions
* Abusing System Linux components

Most of this section will be done in examples which cover some, but not all, important escalation techniques. That said, several helpful references have nearly complete lists of escalation techniques including:

* [PayloadsAllTheThings](https://github.com/swisskyrepo/PayloadsAllTheThings/blob/master/Methodology%20and%20Resources/Linux%20-%20Privilege%20Escalation.md)
* A more updated version from [HackTricks](https://book.hacktricks.xyz/linux-hardening/privilege-escalation)
